# Proposal

## Why

Действия разбиваются на шаги вручную, но один «крупный» шаг часто прячет за собой несколько мелких.
Дописывать их руками долго и муторно. Веса действий мы уже получаем от нейросети; тот же приём
(сформировать промпт → вставить в нейросеть → вставить ответ обратно) естественно перенести на шаги,
чтобы грубый шаг разворачивался в точный чеклист. Переименование панели в «API AI» фиксирует, что блок
больше не только про веса и в перспективе уедет с ручной вставки на API.

## What Changes

- Панель на странице кейса «Оценка нейросетью» переименовывается в **API AI** (в ней остаётся поток весов действий).
- Новый поток **«Уточнить шаг»** — сворачиваемая секция внутри каждого действия, после «изменить» и
  «обоснование нейросети»: выбрать шаг по номеру, сформировать промпт, вставить ответ — шаг разбивается на под-шаги.
- Каждый шаг в чеклисте действия получает **номер** (1, 2, 3, …), по которому на него можно сослаться.
- Новый поток «Уточнить шаг»: выбрать шаг по номеру (и действию), сформировать JSON-промпт с коротким
  общим контекстом и списком шагов, скопировать в нейросеть, вставить ответ обратно — выбранный шаг
  заменяется на возвращённые под-шаги.
- Для детализации — **отдельный** промпт-шаблон и отдельная схема ответа (не та, что у весов).
- Схемы ответов **взаимно несовместимы**: ответ для весов нельзя применить в «Уточнить шаг» и наоборот.
- На этом этапе вставка ответа остаётся ручной; API — отдельная будущая работа.

## Capabilities

### New Capabilities

- `step-refinement`: разворачивание грубого шага действия в более мелкие под-шаги по ответу нейросети —
  нумерованные шаги, выделенный поток «Уточнить шаг» внутри панели «API AI».

### Modified Capabilities

_Нет — спецификаций в проекте пока нет._

## Impact

- `templates/case.html` — переименование панели, новый подблок «Уточнить шаг», нумерация шагов.
- `model.go` — у шага появляется порядок/позиция; логика замены шага на под-шаги.
- `prompt.go` + новый шаблон (напр. `refine.tmpl`) — сборка промпта детализации и своя схема ответа.
- `server.go`, `edit.go` — новые маршруты: промпт детализации, импорт/применение ответа.
- `static/style.css` — минимальные стили под новый блок и номера шагов.
